FAQ

Common questions

What parents ask before installing it on a child's phone.

Is Acutis Firewall really free?

Yes. It is MIT-licensed open source with no ads, no subscription, no in-app purchases and no account. Donations are optional and pay for test devices, blocklist hosting and the work of keeping the app running on new Android releases.

Does it need root?

No. It uses Android's standard VpnService API to filter DNS on the device itself, on Android 10 or higher. No root, no custom ROM, no computer.

Can my child uninstall it?

Optional uninstall protection registers the app as a device admin, which blocks uninstall, force stop and clearing storage; turning it off needs the PIN. Android still lets a determined user deactivate a device admin in Settings, and the app alerts you when that happens. Device Owner mode is the only fully unremovable option. Details in uninstall protection.

Will it slow the phone down?

No. Only DNS traffic to 8.8.8.8 and 8.8.4.4 is routed through the local tunnel; every other connection bypasses it entirely. There is no proxy and no remote server in the path.

Does it collect data?

No. There are no analytics and no developer server. DNS queries are answered on the device, and blocklists are downloaded from public GitHub and GitLab lists. Nothing about your child's browsing leaves the phone — see the privacy policy.
